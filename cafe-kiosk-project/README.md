# 우리 카페 키오스크

GitHub Pages로 배포할 수 있는 정적 웹 키오스크의 시작 프로젝트입니다.

## 현재 구현된 기능
- 첫 화면 및 카페 이름 표시
- 매장에서 먹고 가기 선택
- 포장하기 선택
- 선택 결과 확인 화면
- 뒤로 가기
- 모바일·태블릿·PC 반응형 레이아웃

## 폴더 구성

```text
cafe-kiosk-project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## GitHub에 올리는 방법
1. 저장소 최상위(root)에 `index.html`을 올립니다.
2. `css` 폴더와 그 안의 `style.css`를 올립니다.
3. `js` 폴더와 그 안의 `app.js`를 올립니다.
4. GitHub 저장소의 Settings → Pages에서 `main` 브랜치, `/(root)`를 선택합니다.

주의: 폴더 구조와 파일 이름의 대소문자를 그대로 유지해야 합니다.
